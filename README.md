# FeedbackSense 💬
An AI-powered app to cluster and analyze user feedback, revealing common themes and sentiment.

## Features
- Groups feedback using KMeans clustering
- Performs sentiment analysis with TextBlob
- Visualizes distribution of user sentiment

## Run
```bash
pip install -r requirements.txt
streamlit run main.py
```
